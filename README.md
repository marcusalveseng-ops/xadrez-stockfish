# Chess — publicação consolidada

O desenvolvimento foi consolidado em [chess-master-trainer](https://github.com/marcusalveseng-ops/chess-master-trainer), que preserva o histórico e o código completo. Este repositório mantém somente a exportação estática para transferir a publicação à Tess; não é uma segunda fonte de desenvolvimento.

Endereço existente: https://xadrez-stockfish.tess.page/

O arquivo index.html reúne Stockfish, assistente com três variantes, vantagens e riscos, 205 partidas PGN e histórico local compatível. Gerado pelo comando pnpm build:tess no repositório principal.

SHA-256 de index.html: `93b38fe91075c44f0b82a67a9c6b7bf33a0b25999f70bfe7270d7d3121be8e10`.

O GitHub não publica automaticamente na Tess. O HTML deve ser republicado na conversa original da página, mantendo o mesmo subdomínio. Nenhum domínio adicional foi contratado.
